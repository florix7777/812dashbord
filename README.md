# Dashboard SC

Дашборд контроля качества звонков и взыскания для Soft Collection Unit.

**Версия 1.4.0.** Данные берутся из Excel и PDF, которые тимлиды загружают прямо на сайте (кнопка «Загрузить отчёт»). Сайт сам определяет тип файла, читает его и обновляет базу без дублей.

## Что умеет
- **Аналитика, Рейтинг, Прогноз** по неделям и месяцам (периоды как в отчётах QC: 01-09, 10-16, 17-23, 24-31).
- **Взыскание**: любой период (от и до), оператор или весь отдел, рост к предыдущему периоду, % плана. Суммы можно загружать накопленными с начала месяца или за день.
- **Контроль по дням**: оценки по дням и неделям, критерии, отдельные звонки с комментариями проверяющего.
- **Сотрудники**: новые добавляются сами из файлов, похожие имена предлагается объединить, уволенных можно отключить.
- **База знаний**: возражения, инструментарий, мануал, регламенты.

## Какие файлы принимает загрузка
| Файл | Что внутри |
|---|---|
| Excel «Оценки звонков» | по одному звонку в строке, колонки как в `Quality_*.xlsx`; месяц и неделя определяются по датам звонков |
| Excel «Взыскание» | колонки Оператор, Дата, Собрано (или «с начала месяца» / «за день»), План; шаблон: `assets/templates/collection_template.xlsx` |
| Excel «CRM-действия» | Оператор и колонки действий |
| PDF «Промежуточный отчёт по сотрудникам» | тенденции и рекомендации по неделям (нужны уже загруженные оценки за этот месяц) |

## Устройство
```
nginx (сайт, порт 8080) -> backend FastAPI (/api, разбор файлов) -> PostgreSQL
```
`backend/parsing.py` читает файлы, `backend/store.py` пишет в базу и ведёт список сотрудников, `backend/importer.py` загружает отчёты из папки.

Запуск и обновление: см. `DEPLOY.md`. Тесты: `pytest -q tests`.
